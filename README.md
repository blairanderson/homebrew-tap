# blairanderson/homebrew-tap

Homebrew tap for [Blair Anderson](https://github.com/blairanderson)'s tools.

## Formulae

### hatchbox

Zero-dependency Ruby CLI for the [Hatchbox.io](https://app.hatchbox.io) API.

```sh
brew install blairanderson/tap/hatchbox
```

Source: https://github.com/blairanderson/hatchbox-cli
